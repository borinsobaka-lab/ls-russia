# ADR platform-005: хранение и редактирование статей базы знаний

Статус: предложено — 2026-10-08

## Контекст

База знаний — первый продукт релиза. Собственникам и УК нужны правка в
браузере, черновики, история, доступ по ролям, подтверждение
ознакомления, поиск с морфологией. Статика из markdown-файлов в git
(правка = PR разработчика) этому не отвечает.

## Варианты

1. Markdown в базе + редактор markdown. Таблицы, выноски, вложения,
   видео и ссылки на задачи не выражаются стандартным markdown —
   получится свой диалект без WYSIWYG.
2. HTML в базе. XSS-поверхность; не поддаётся структурным операциям
   (оглавление, миграции формата).
3. **JSON-документ ProseMirror (TipTap) в базе** (выбрано). Структура
   со схемой; HTML для чтения и текст для поиска строит сервер при
   публикации; схема расширяется узлами («выноска», «чек-лист», «ссылка
   на задачу»); тот же редактор годится для описаний задач и длинных
   сообщений; есть путь к совместному редактированию (Yjs).
4. Внешняя вики (Outline, BookStack, Wiki.js). Отдельный вход, роли,
   бэкапы, вторая база; сквозная связка «статья → задача всем, кто не
   прочитал» не получится.

## Решение

- `kb_article_versions.content jsonb` — документ ProseMirror; при
  публикации сервер пишет `content_html` (рендер той же схемой +
  санитайзер) и `content_text` (для `tsvector`).
- Редактор — TipTap с набором узлов из `packages/shared/src/kb-schema.ts`
  (один источник для редактора, рендера и серверной валидации;
  неизвестный узел отвергается).
- Картинки и файлы — приватный бакет `kb-files`, в документе — ссылка
  на `files.id`, адрес собирается при показе. Видео — узел `embed` с
  белым списком российских хостингов.
- Поиск — `tsvector` конфигурации `russian` (заголовок A, описание B,
  текст C) + `pg_trgm` по заголовку; под RLS.
- Интерфейс чтения — три колонки (меню с описаниями, текст до 740 px,
  оглавление с подсветкой), стрелки «назад/дальше», темы, печать.
- Версии не редактируются и не удаляются; «удалить статью» — архив.

## Последствия

- Зависимости: `@tiptap/*`, `prosemirror-*`, `sanitize-html`. Чанк
  редактора — ленивый `next/dynamic`, читатель его не грузит.
- Экспорт в PDF и импорт из Word — задачи релиза 2 поверх того же JSON.
- Описание задачи и длинные сообщения чатов используют урезанную схему
  того же редактора — одна санитизация.
