# ADR platform-004: уведомления сотрудникам

Статус: предложено — 2026-10-08

## Контекст

Задачи и чаты без уведомлений — система, в которую никто не заходит.
Пользователи — на личных телефонах (iPhone и Android поровну), часть —
за компьютером. Web Push на Android идёт через FCM, на iPhone работает
только из установленной PWA (iOS 16.4+); из России доступность FCM и
APNs не гарантирована. Почта есть у всех. Telegram — почти у всех.

## Варианты

1. Только push — отклонено: iPhone без установки и любое отключение
   FCM/APNs оставляют человека без уведомлений.
2. Только письма — отклонено: медленно для чатов, спам-фильтры.
3. **Четыре слоя с одним источником правды** (выбрано): лента в портале
   (`notifications`, всегда) → push → письмо («не прочитано за 10 минут»
   для личных и упоминаний; дайджест для остального) → Telegram-бот (по
   желанию пользователя, релиз 2).

## Решение

- **Кому адресовано, решает база**: событие (сообщение, назначение,
  упоминание, смена статуса, срок, статья с `requires_ack`) порождает
  строки `notifications` триггером или RPC с учётом членства и
  `notification_prefs`; текст собирается при показе из `kind` + `vars`.
- **Доставка — только воркером** через `jobs` (`notify.push`,
  `notify.email`, `notify.telegram`), никогда синхронно в запросе.
  Временная ошибка — повтор с экспонентой; 404/410 — подписка мертва;
  400/403 — отказ. Белый список хостов push против SSRF.
- **Письмо через 10 минут**, если уведомление о личном сообщении или
  упоминании не прочитано — одно письмо на чат за окно. Дайджест групп,
  каналов и задач — вечером по часовому поясу клуба (`pg_cron` → `jobs`).
- **Тихие часы** и `muted_until` уважаются всеми каналами, кроме ленты.
- **Push без персональных данных в теле**: «Новое сообщение в чате
  „Открытие Казань“» — да; текст сообщения — нет (FCM и APNs за
  границей).
- Прочтение гасит уведомление **действием** (открыл чат, открыл задачу)
  и отменяет неотправленное письмо (`subject_key`).
- Telegram-бот (релиз 2): привязка по одноразовому коду из портала
  (`telegram_links`), тот же текст, кнопка «Открыть»; ответить из
  Telegram нельзя — это уведомление, а не второй мессенджер.
- Статистика: «отправлено», «прочитано»; «доставлено» не обещаем.

## Последствия

- Лента в портале — обязательный раздел релиза 1 с ярлыком
  непрочитанного; её пересчитывает SSE-канал.
- PWA-установка нужна ради push на iPhone; инструкция — слой в лейауте.
- Нагрузка на почту растёт с числом непрочитанных: Unisender Go по
  объёму, письма с `track_links: 0`.
