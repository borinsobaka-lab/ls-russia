# Языки, фреймворки, библиотеки и инструменты

Статус: предложено — 2026-10-08. Это ответ на вопрос «на чём писать».
Критерии выбора: один язык на всех слоях, зрелость и предсказуемость,
работа из России без зарубежных зависимостей на критическом пути,
удобство для разработки через Claude Code (популярные технологии модель
знает лучше редких), самостоятельный хостинг.

## 1. Языки

| Слой | Язык | Почему |
|---|---|---|
| Фронтенд, сервер приложений, воркер, скрипты проверок | **TypeScript** (strict), Node.js 22 LTS | один язык и одни типы от базы до экрана; контракты базы зеркалятся типами в `packages/shared`; экосистема Next.js и Supabase — TypeScript-first |
| Схема, права, транзакционная логика | **SQL + PL/pgSQL** (Postgres 15+) | изоляция данных и целостность живут в базе: политики RLS, security-definer-функции, триггеры-сторожа, замки; это единственный слой, который нельзя обойти из клиента |
| Операционные скрипты (миграции, тесты базы, CI) | **bash** | применение миграций, одноразовый Postgres для тестов, выбор затронутых приложений — короткие сценарии без зависимостей |
| Мобильные приложения | **нет отдельного языка**: PWA на том же TypeScript, позже оболочка Capacitor для магазинов | нативный Swift/Kotlin понадобится только ради возможностей, которых нет у веба (NFC, глубокий фон); для записи, расписания и оплаты — не нужен |

Чего нет намеренно: Python (нет задач, где он выигрывает — ИИ ходит
через HTTP API поставщика), Go/Rust (нет узких мест по
производительности, которые оправдали бы второй рантайм), отдельного
бэкенд-фреймворка (NestJS, Express) — сервер живёт внутри Next.js.

`apps/portal`, `apps/client` (релиз 3), `packages/shared`.

ESLint и Prettier на старте не ставятся: проверка — строгие типы и
прод-сборка в CI; форматирование добавляется по желанию владельца
одним PR.

## 3. Данные и сервер

| Технология | Роль |
|---|---|
| **PostgreSQL** 15+ (образ `supabase/postgres`) | единственная база; расширения `pgcrypto`, `pg_trgm` (поиск с опечатками), `pg_cron` (расписания), `pg_stat_statements`; полнотекстовый поиск — `tsvector` с конфигурацией `russian` |
| **PostgREST** | HTTP-доступ к базе под RLS; все чтения и записи приложений идут через него ключом пользователя |
| **GoTrue** (Supabase Auth) | почта + пароль + TOTP для сотрудников; выдаёт JWT с клеймом `aal` |
| **Supabase Storage** + **imgproxy** | файлы в S3-совместимом хранилище, подписанные ссылки, преобразования картинок |
| **Kong** | шлюз Supabase: один внешний адрес `api.<домен>` |
| **Supabase Studio** | просмотр данных (только просмотр: схема меняется миграциями) |

Чего нет намеренно: Supabase Realtime (живые обновления — SSE из
процесса приложения), Edge Functions (логика — в приложении и в
функциях базы), Redis (очередь и кеш — Postgres и память процесса),
Elasticsearch (поиск — Postgres), отдельного брокера сообщений.

## 4. Инфраструктура и эксплуатация

| Технология | Роль |
|---|---|
| **Docker** (multi-stage, `node:22-alpine`) | один образ на приложение; из образа портала запускаются веб и воркер (`PORTAL_ROLE=worker`) |
| **Coolify** | self-hosted PaaS: выкат по push в `main`, TLS через Traefik + Let's Encrypt, бэкапы баз в S3, веб-терминал |
| **Timeweb Cloud** | серверы в Москве, S3 в Санкт-Петербурге, DNS, файрвол, VPC, балансировщик |
| **GitHub + GitHub Actions** | репозиторий и проверки на PR: быстрые проверки, тест базы, сборка, Playwright — только по затронутому |
| **Playwright** | браузерные сценарии для живых обновлений, PWA и редактора |
| **node:test** | юнит-тесты чистых функций в `packages/shared` |
| **GlitchTip** | ошибки (self-hosted, протокол Sentry) |
| **Uptime Kuma** | аптайм и пульс воркера, тревоги в Telegram |
| **Grafana + Prometheus + Loki + Alloy** | метрики и логи — вторым этапом |

## 5. Внешние сервисы (все российские, кроме неизбежных)

| Назначение | Сервис | Примечание |
|---|---|---|
| Транзакционная почта | **Unisender Go** (HTTP API) | домен-отправитель с DKIM/SPF/DMARC |
| Push на телефон | **Web Push** (FCM у Android, APNs у iPhone) | единственная зарубежная зависимость; в теле push нет персональных данных; при недоступности работают лента и письма |
| Уведомления в мессенджере | **Telegram Bot API** | релиз 2; из российских ЦОД доступен по IPv6 |
| SMS (вход клиентов, релиз 3) | российский шлюз (SMS Aero / SMSC / MTS Exolve) | через хук отправки GoTrue или свой модуль |
| Платежи (релиз 3) | **ЮKassa / CloudPayments / Т-Банк** | чеки 54-ФЗ через кассу шлюза |
| Переписка с клиентами (релиз 4) | **Telegram Bot API, MAX Bot API, VK** | WhatsApp в России заблокирован с февраля 2026 — не планируется |
| ИИ | **Яндекс** (AI Studio, SpeechKit, Vision) | API Anthropic из России не открывается; API Сбера требует сертификатов НУЦ; слой `lib/ai/` держит интерфейс поставщика |
| Капча (публичные формы, релиз 3) | **Yandex SmartCaptcha** | бесплатна |
| Видео в статьях | ссылки на Kinescope / VK Video / RuTube | белый список доменов для встраивания |

## 6. Инструменты разработки

- **Claude Code** (веб) — основной способ писать код; правила для сессий
  — `CLAUDE.md` корня и приложения, решения — ADR, процесс —
  `docs/setup/03-claude-code-workflow.md`.
- Локально разработчику нужны только Node 22, pnpm и Docker (для
  одноразового Postgres под тесты базы — либо локальный PostgreSQL).
- Переменные окружения — `apps/portal/.env.example` с комментариями;
  значения — только в Coolify и менеджере паролей.
